== Description ==

**Elonix – Toolkit for Elementor** is a complete all-in-one Toolkit for Elementor plugin that empowers you to build professional websites with ease — without touching a single line of code.

Whether you need custom headers, footers, popups, archive layouts, or beautiful widgets, Elonix – Toolkit for Elementor has you covered.

= Key Features =

* **Header & Footer Builder** — Design custom headers and footers with full Elementor control.
* **Popup Builder** — Create stunning popups with advanced display conditions.
* **Archive Builder** — Custom archive templates for posts, categories and custom post types.
* **Single Post Builder** — Full control over single post layouts.
* **404 Page Builder** — Design beautiful custom 404 error pages.
* **Search Builder** — Customize search result pages.
* **Screen Loader** — Add elegant loading screens to your website.
* **Template Library** — One-click import of pre-built templates.
* **30+ Elementor Widgets** — Including Nav Menu, Post Block, Gallery, Testimonial, Marquee, Progress, Toggle, and many more.
* **Dynamic Tags** — 40+ dynamic tags for ACF, WooCommerce, post meta, author info, and more.
* **Custom Post Types** — Built-in Services, Projects, Teams, and Gallery CPTs.
* **Import / Export** — Easily backup and restore your settings.
* **Lightweight & Fast** — Modular architecture loads only what you enable.

== Installation ==

1. Upload the entire `elonix` folder to the `/wp-content/plugins/` directory, OR install via **Plugins > Add New** in your WordPress dashboard.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Make sure **Elementor** is installed and activated.
4. Go to **Elonix > Dashboard** to enable/disable modules and widgets.
5. Start using the new widgets inside your Elementor editor under the **Elonix** widget category.

== Frequently Asked Questions ==

= Does this plugin require Elementor? =

Yes. Elonix – Toolkit for Elementor is designed as an addon for the Elementor Page Builder. Both the free Elementor plugin and Elementor Pro are supported.

= Is this plugin compatible with all WordPress themes? =

Yes, Elonix – Toolkit for Elementor works with any WordPress theme. For best results, use a theme that is compatible with Elementor.

= Can I use this to build custom headers and footers? =

Absolutely. The Header & Footer Builder module lets you design fully custom header and footer layouts using Elementor and assign them to any page or condition.

= Can I disable widgets I don't need? =

Yes. Go to **Elonix > Widgets** to enable or disable individual widgets. Disabled widgets do not load any assets, keeping your site fast.

= Can I disable modules I don't need? =

Yes. Go to **Elonix > Modules** to enable or disable individual modules like Popup Builder, Header Builder, etc.

= Does it support WooCommerce? =

Yes. Elonix – Toolkit for Elementor includes WooCommerce dynamic tags and widget support for product data.

= How do I import a template? =

Go to **Elonix > Template Library**, browse the available templates, and click **Import** on any template you like.
